    08 · 接口需求¶

    本章描述内部 API 规范、与三方对接的关键点。
    API 详细字段以 OpenAPI 3.0 文档为准（仓库 api/openapi.yaml），本章给出设计原则与关键列表。

    8.1 设计原则¶

    1. RESTful 风格：资源名词复数，HTTP method 表示动作；查询参数过滤、分页。
    2. 统一前缀：/api/v1/...
    3. 统一响应：
    {
  "code": 0,
  "message": "ok",
  "data": { ... },
  "trace_id": "abc123"
}
    1. 错误码：业务码 5 位（10001~19999），系统码 6 位（500xxx）。
    2. 鉴权：除登录、注册、找回密码外，全部接口需 Authorization: Bearer <jwt>。
    3. 幂等：所有写接口支持 Idempotency-Key 头，24h 内同 key 不重复执行。
    4. 分页：page（从 1 起）、page_size（默认 20，最大 100），返回 total、has_more。
    5. 时间：所有时间字段 ISO8601 + 时区（+08:00）。

    8.2 三端接入¶

    端 接入方式
    iOS / Android HTTPS + JWT；可使用证书 pinning
    小程序 HTTPS + JWT；referer 校验
    运营后台 Web HTTPS + JWT + 短期 access token + 双因素

    8.3 患者端关键 API¶

    8.3.1 账号¶

    方法 路径 说明
    POST /api/v1/auth/sms/send 发送短信验证码
    POST /api/v1/auth/login 登录（手机号+验证码 / 微信）
    POST /api/v1/auth/refresh 刷新 token
    POST /api/v1/users/real-name/auth 提交实名
    GET /api/v1/users/me 我的信息

    8.3.2 医院与服务包¶

    方法 路径 说明
    GET /api/v1/hospitals 医院列表（按 city / keyword）
    GET /api/v1/hospitals/{id} 医院详情
    GET /api/v1/hospitals/{id}/packages 服务包列表

    8.3.3 下单与支付¶

    方法 路径 说明
    POST /api/v1/orders/price-preview 价格试算（含优惠券）
    POST /api/v1/orders 创建订单
    POST /api/v1/orders/{id}/pay 发起支付（返回微信 prepay）
    POST /api/v1/orders/{id}/cancel 取消
    GET /api/v1/orders 我的订单列表
    GET /api/v1/orders/{id} 订单详情

    8.3.4 评价与售后¶

    方法 路径 说明
    POST /api/v1/orders/{id}/review 提交评价
    POST /api/v1/orders/{id}/refund 申请退款
    POST /api/v1/tickets 创建工单（投诉/咨询）

    8.3.5 个人中心¶

    方法 路径 说明
    GET /api/v1/coupons 我的优惠券
    GET /api/v1/addresses 地址列表
    POST /api/v1/addresses 新增地址
    PUT /api/v1/addresses/{id} 修改地址
    DELETE /api/v1/addresses/{id} 删除地址

    8.4 陪诊师端关键 API¶

    8.4.1 入驻¶

    方法 路径 说明
    POST /api/v1/escorts/apply 提交入驻申请
    POST /api/v1/escorts/qualifications 上传证件
    GET /api/v1/escorts/me 我的档案
    GET /api/v1/trainings 培训课程
    POST /api/v1/trainings/{id}/complete 完成课程
    POST /api/v1/trainings/exam 提交考试

    8.4.2 抢单 / 服务¶

    方法 路径 说明
    PUT /api/v1/escorts/me/online 切换在线状态
    GET /api/v1/orders/feed 抢单池
    POST /api/v1/orders/{id}/accept 接单
    POST /api/v1/orders/{id}/reject 拒绝（抢单后）
    POST /api/v1/orders/{id}/checkin 到院签到
    POST /api/v1/orders/{id}/timeline 添加时间线节点
    POST /api/v1/orders/{id}/finish 结束服务

    8.4.3 钱包¶

    方法 路径 说明
    GET /api/v1/wallet 钱包余额
    GET /api/v1/wallet/bills 账单明细
    POST /api/v1/wallet/withdrawals 申请提现
    GET /api/v1/wallet/withdrawals 提现记录

    8.5 运营后台关键 API¶

    模块 路径前缀 说明
    仪表盘 /admin/v1/dashboard KPI、异常告警
    用户 /admin/v1/users 患者 / 陪诊师管理
    医院 /admin/v1/hospitals CRUD
    服务包 /admin/v1/packages CRUD
    订单 /admin/v1/orders 查询 + 干预
    陪诊师审核 /admin/v1/escorts/audit 审核工作台
    财务 /admin/v1/finance 对账、提现审核
    优惠券 /admin/v1/coupons CRUD + 投放
    工单 /admin/v1/tickets 客服工作台
    报表 /admin/v1/reports 多维报表
    配置 /admin/v1/configs 系统配置

    全部 /admin/v1/... 仅内网可访问，且需 admin 角色 + 二次验证。

    8.6 三方对接¶

    8.6.1 微信生态¶

    能力 用途 接入方式
    微信登录 App / 小程序一键登录 OAuth2.0、code2Session
    微信支付 订单支付 JSAPI（小程序）、App 支付
    微信模板消息 服务通知（小程序） subscribeMessage
    客服消息 客服回复 客服 API
    微信分享 拉新分享 wx.share / sdk

    8.6.2 实名 / 活体¶

    • 场景：注册、提现
    • 服务商：阿里云实人认证 / 腾讯云慧眼 / 网易易盾（三选一或双备）
    • 接口：提交身份证 + 姓名 + 活体视频 / 照片
    • 存储：仅保留哈希 + 末四位

    8.6.3 短信¶

    • 场景：验证码、通知
    • 服务商：阿里云 / 腾讯云
    • 模板：需提前报备

    8.6.4 推送¶

    • 端：iOS（APNs）、Android（厂商通道 + 第三方推送）、小程序（模板消息）
    • 服务商：个推 / 极光 / 腾讯移动推送 / 阿里移动推送
    • 策略：按用户分通道，避免打扰

    8.6.5 地图 / 定位¶

    • 服务商：高德 / 腾讯
    • 能力：定位、地址解析、距离计算、医院 POI

    8.6.6 银行 / 打款¶

    • 场景：陪诊师提现、企业付款
    • 通道：微信企业付款到零钱 / 银行卡
    • 要求：商户号开通"企业付款"权限；合规留存付款凭证

    8.6.7 文件存储¶

    • 场景：证件照、过程照片
    • 服务商：OSS / COS
    • 安全：上传走服务端中转 + 签名 URL；不开放前端直传 OSS

    8.7 接口安全清单¶

    • 所有接口必须鉴权（除登录、注册、验证码、公开配置）
    • 所有写接口必须幂等
    • 限流：登录 5/min/IP、验证码 1/60s/手机号、下单 5/min/用户
    • 错误响应不得泄漏堆栈、SQL、内部地址
    • 跨域：仅允许配置的白名单
    • 敏感字段（身份证、电话）响应必须脱敏

    8.8 错误码规范¶

    范围 含义
    0 成功
    1xxx 通用业务（参数、状态、权限）
    11xx 账号相关
    12xx 订单相关
    13xx 支付相关
    14xx 评价相关
    15xx 陪诊师相关
    2xxx 资源 / 数据不存在
    3xxx 三方调用失败（微信 / 实名 / 短信）
    4xxx 风控拦截
    5xxxx 系统异常

    客户端需按 code 做用户可读提示，不能直接展示后端 message。

    8.9 接口 Mock 与联调¶

    • 研发阶段：平台提供 mock 服务（推荐 YApi / Apifox）
    • 联调阶段：staging 环境 + 微信沙箱
    • 上线前：完整 OpenAPI 文档 + Postman 集合 + 示例
