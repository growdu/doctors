    3.1 公共能力¶

    3.1.1 账号与登录¶

    注册¶

    • 入口：App / 小程序首页 → "立即注册"
    • 方式：
    • 手机号 + 短信验证码（必选）
    • 微信一键登录（拉取 unionid，生成账号）
    • 必填项：手机号、验证码、角色选择（patient / escort）
    • 校验：
    • 手机号格式 + 唯一性
    • 短信验证码 60s 内有效，错误次数限制 5 次
    • 同一设备 24h 内最多注册 3 个账号（防刷）
    • 异常：
    • 短信发送失败：提示"稍后重试"，并允许"语音验证码"
    • 微信授权失败：提示并降级为手机号注册

    登录¶

    • 方式：手机号 + 验证码 / 微信一键
    • 安全：
    • 异地 / 新设备登录触发二次验证（短信 + 人脸可选）
    • 连续 5 次密码 / 验证码错误锁定 30 分钟
    • 登录态：JWT access token（2h） + refresh token（30d）

    找回 / 修改¶

    • 找回密码 / 修改手机号 / 修改密码：均需短信验证码
    • 修改手机号需老手机号二次确认

    注销¶

    • 注销前必须：清空钱包余额、处理未完成订单、解除所有绑定
    • 注销后账号冻结 30 天（防误操作），30 天后物理删除 PII（保留必要的财务凭证）

    3.1.2 实名认证¶

    • 入口：个人中心 → 实名认证 / 下单前置
    • 流程：
    • 填写真实姓名 + 身份证号
    • 调用第三方实名服务（公安二要素 + 活体）
    • 通过 → 标记 real_name_verified = true，仅保留哈希 + 末四位
    • 失败处理：可重试 3 次；仍失败引导人工客服
    • 合规：实名信息加密存储；展示时全部脱敏（如 110****1234）

    3.1.3 消息中心¶

    • 类型：
    • 系统通知（如订单状态、培训提醒）
    • 业务通知（订单进度、评价提醒）
    • 客服消息
    • 通道：App Push（个推 / 极光）+ 微信模板消息（小程序）+ 短信（兜底）
    • 用户偏好：可关闭"非必要通知"，但订单状态变更不可关闭

    3.1.4 客服与帮助¶

    • 入口：个人中心 → 在线客服
    • 形态：智能客服（FAQ） + 转人工
    • 能力：订单查询、投诉、咨询、退款进度查询

    3.1.5 支付与发票¶

    • 支付通道：微信支付（小程序 / App 共享同主体）
    • 支付方式：服务费预付 + 完成后补差价
    • 退款：原路退回；工作日 1-3 个工作日到账
    • 发票：
    • 普通电子发票（默认）、增值税专票（需企业资质）
    • 自助开具：订单完成后可申请，5 个工作日内出票

    3.2 患者端功能¶

    3.2.1 首页¶

    模块 内容
    Banner 平台公告、活动、安全提示
    快捷入口 代挂号、代取报告、半日陪诊、全日陪诊
    推荐医院 基于位置推荐附近热门医院
    推荐陪诊师 评分高 + 距离近（脱敏展示）
    我的订单 状态卡（待支付、进行中、待评价）

    3.2.2 医院浏览¶

    • 列表：按城市、按距离、按热门排序
    • 筛选：医院等级（三级 / 二级）、专科特色、是否医保
    • 详情页：
    • 医院简介、地址、联系电话、交通指引
    • 支持的服务包列表
    • 历史服务评价（脱敏）
    • 收藏 / 分享：可收藏医院到"我的"，可分享给微信好友

    3.2.3 下单流程¶

    这是最重要的端到端流程。

    步骤 用户操作 系统动作
    1. 选择医院 浏览或搜索 展示医院列表
    2. 选择服务包 半日 / 全日 / 代取报告 / 定制 计算价格、显示明细
    3. 选择时间 日期 + 时段 校验陪诊师可用性
    4. 选择陪诊师 系统匹配 / 自选 匹配规则见 04
    5. 填写就诊信息 患者姓名 / 性别 / 年龄 / 病情描述（可选）/ 紧急联系人 加密存储
    6. 选择优惠券 自动匹配可用券 计算最终价
    7. 支付 微信支付 调用微信下单
    8. 下单成功 返回订单详情 触发匹配 / 推送接单

    校验：

    • 下单前未实名 → 弹窗引导实名
    • 同一患者同时存在的"待匹配"订单 ≤ 2（防囤单）
    • 时间必须在未来 2h 之后（避免即时单难以匹配）

    异常分支：

    • 长时间未匹配（> 30 分钟）：自动提示"是否扩大匹配范围 / 改时间 / 退款"
    • 匹配后陪诊师拒绝：自动重试匹配，最多 N 次；仍失败人工介入

    3.2.4 我的订单¶

    • Tab：全部 / 待支付 / 待匹配 / 进行中 / 待评价 / 已完成 / 已取消
    • 订单详情：
    • 状态机可视化
    • 陪诊师信息（电话可点击拨打，需双方同意开启虚拟号）
    • 任务卡：就诊科室、医生、时间、地址、注意事项
    • 操作：取消、改时间、申请发票、联系客服、评价

    3.2.5 评价¶

    • 时机：订单状态 = 已完成，且未评价
    • 维度：
    • 星级（1~5）
    • 标签（专业、守时、有耐心、熟悉流程……）
    • 文字评价（≤ 500 字）
    • 匿名选项
    • 追加 / 修改：提交后 24h 内可修改一次

    3.2.6 个人中心¶

    • 头像 / 昵称 / 实名状态
    • 我的订单、我的评价、我的收藏、我的优惠券
    • 钱包（余额、充值记录）
    • 设置：通知开关、隐私设置、注销账号
    • 关于我们 / 用户协议 / 隐私政策 / 联系客服

    3.2.7 安全相关¶

    • SOS 一键报警：长按 3s 触发，向紧急联系人发送定位 + 自动拨打 110
    • 行程上报：服务进行中，平台定期获取陪诊师 / 患者位置（用户授权）
    • 虚拟号：陪诊师与患者互拨通过平台中转的虚拟号码，保护真实号码

    3.3 陪诊师端功能¶

    3.3.1 工作台首页¶

    模块 内容
    今日待办 待服务订单数、待补差价、待提现金额
    抢单池 实时可抢订单流
    数据卡片 本月完成单数、收入、评分
    培训入口 必修课程、未完成提醒
    资质状态 健康证有效期、年审提醒

    3.3.2 注册入驻流程（陪诊师专属）¶

    这是陪诊师上线的全流程。

    步骤 内容 说明
    1. 注册 手机号 + 验证码 + 角色 = 陪诊师 同通用注册
    2. 个人信息 头像、昵称、性别、年龄、城市、所在区
    3. 实名认证 姓名 + 身份证 + 活体
    4. 健康证 上传健康证照片 + 有效期 必填
    5. 资质材料 学历证书、医护背景（护士证 / 医师证等）、其他证书 选填但加分
    6. 服务范围 擅长医院、擅长科室、擅长人群、可服务时段 用于匹配
    7. 培训学习 完成必修课程（视频 + 图文） 必须 100% 完成
    8. 培训考核 在线试卷（≥ 80 分通过） 多次机会，记录最佳成绩
    9. 协议签署 《陪诊师服务协议》《隐私承诺》 电子签
    10. 审核 运营人工审核（1~3 工作日）
    11. 上线 进入抢单池

    状态机：

    注册 → 资料填写中 → 培训中 → 待审核 → 审核通过（可接单）
                              ↓
                          审核拒绝（可修改后重新提交）

    3.3.3 抢单 / 接单¶

    • 抢单池：平台按地理 + 时间 + 技能匹配的订单，按距离 / 时薪排序
    • 接单方式：
    • 抢单（先到先得，30s 锁单）
    • 派单（平台强派，通常仅用于稀缺时段或专业技能匹配）
    • 限制：
    • 同一时段最多持有 1 单
    • 接单前必须处于"在线"状态
    • 接单后 5 分钟内必须确认，否则超时自动放单并扣信用分

    3.3.4 服务执行¶

    • 到院签到：必须到院后才能签到，校验 GPS 距离医院 ≤ 500m
    • 关键节点打卡：
    • 到达医院
    • 挂号完成
    • 候诊中
    • 就诊完成
    • 取药 / 取报告完成
    • 离院
    • 过程上传（可选）：服务过程中可拍照上传照片（如挂号单、检查单），便于患者子女远程查看
    • 服务结束：填写实际服务时长、是否有补差价，提交"结束服务"
    • 异常上报：患者未到、患者爽约、突发情况等可一键上报

    3.3.5 钱包与提现¶

    • 收入构成：订单收入 + 奖励（高峰补贴、新人奖）
    • 结算规则：T+7 结算（即订单完成后 7 天可提现，规避退款风险）
    • 提现：本人微信钱包 / 银行卡，单笔 ≥ 100 元起，工作日 24h 内到账
    • 账单明细：所有收支可查询

    3.3.6 培训与考核¶

    • 课程分类：
    • 必修：医院就诊流程、应急处理、平台规则、服务礼仪、隐私合规
    • 选修：专科知识（妇产、肿瘤、儿科等）
    • 考核：每季度复训 + 考核；不通过暂停接单

    3.3.7 评价与申诉¶

    • 查看患者对自己的评价（脱敏后展示）
    • 对差评可申诉（仅一次机会），需提供证据
    • 被投诉 → 平台介入 → 视情节扣分 / 暂停 / 清退

    3.3.8 个人中心¶

    • 同患者端基础模块
    • 额外：
    • 我的评分、历史单数、收入统计
    • 资质中心（证件有效期、年审）
    • 接单设置（可服务时段、距离偏好、是否接受派单）

    3.4 管理后台功能（Web）¶

    3.4.1 仪表盘¶

    • 关键指标：DAU、订单量、GMV、完单率、平均评分
    • 异常告警：投诉飙升、陪诊师大量请假、某城市订单异常下降
    • 实时大屏（可选）：当日订单热力图

    3.4.2 用户管理¶

    • 患者列表：搜索、筛选、查看详情、冻结、解冻
    • 陪诊师列表：搜索（手机号 / 姓名 / 状态 / 城市）、筛选、详情、审核、上下架
    • 管理员列表：增删改查、角色绑定

    3.4.3 医院与服务包¶

    • 医院：增删改查、上下架、关联服务包
    • 服务包：半日陪诊、全日陪诊、代取报告、定制；配置价格、时长、覆盖范围
    • 价格策略：按城市 / 医院 / 时段差异化

    3.4.4 订单与监控¶

    • 订单列表：多维筛选（状态 / 时间 / 城市 / 金额 / 陪诊师 / 患者）
    • 订单详情：全链路时间线、客服介入入口
    • 异常订单：超时未匹配、超时未签到、投诉中
    • 改派 / 退单：人工干预入口

    3.4.5 陪诊师管理¶

    • 入驻审核：查看资料、通过 / 拒绝 / 退回补充
    • 培训管理：课程上下架、试卷配置、考核记录
    • 投诉处理：查看投诉、约谈、扣分、清退
    • 排班 / 在离线监控（可选）

    3.4.6 财务与结算¶

    • 资金账户：平台总账户、待清算账户、已结算账户
    • 对账：每日与微信支付对账
    • 提现审核：陪诊师提现申请审核
    • 发票管理：发票开具、寄出状态

    3.6 功能优先级（P0/P1/P2）¶

    优先级 含义 本期包含
    P0 必须上线，否则 MVP 无意义 三端基础流程：注册、实名、医院浏览、下单、匹配、接单、服务、支付、评价
    P1 上线后快速补齐 优惠券、抢单池、虚拟号、客服工单、数据看板
    P2 后续版本迭代 直播、AI 智能匹配、健康档案、保险接入、积分商城

    v1.0 优先交付 P0，P1 在 1.0 发布后 1 个月内补齐；P2 进入 backlog。
