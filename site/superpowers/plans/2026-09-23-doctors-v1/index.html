    陪诊师平台 v1.0 MVP 实施计划（阶段 0~4）¶

    For agentic workers: REQUIRED SUB-SKILL: superpowers:test-driven-development / superpowers:verification-before-completion

    Goal: 在 monorepo 内交付"骨架 + 共享库 + auth-service + order-service + match-service"，并实现端到端可跑的"患者登录 → 下单 → 抢单"链路。

    Architecture: Go 1.22 单 module + PostgreSQL 16 + Redis 7 + Kafka；服务间通过 Kafka 解耦，同步通过 gRPC/REST；共享 shared/ 包。

    Tech Stack: Go · pgx + sqlc · go-redis · kafka-go · testify · dockertest

    Global Constraints¶

    • 语言版本：Go 1.22+
    • Lint：golangci-lint v1.59+
    • 测试覆盖率：业务包 ≥ 80%
    • DB：PostgreSQL 16（用 FOR UPDATE SKIP LOCKED 做抢单）
    • 事务：任何写操作必须显式事务（shared/db.WithTx）
    • 响应格式：{"code":0,"message":"ok","data":{},"trace_id":"..."}（shared/httpx）
    • 错误码：业务码 5 位，系统码 6 位
    • Commit：每个测试 + 实现通过立即 commit；前缀 feat/test/fix/chore/docs
    • Branch：直接在 main 推进（小项目，main 即开发线）
