# 01 · 项目概述

## 1.1 业务背景

就医是一项流程复杂、对医院环境不熟悉者门槛极高的活动：

- **大医院**科室多、楼栋分散，自助机、签到、缴费、取报告等环节排队频繁；
- **老年人、孕妇、行动不便者、异地就医、儿童家长**等群体独自就医容易遗漏环节或走错流程；
- **子女异地工作**的父母就医缺少陪伴，但临时请假回乡成本高；
- **慢病复查**、**术前检查**等需要多次往返医院的场景，时间成本高。

**陪诊师** 是经过平台培训、具备一定医疗常识的非医务人员，专门提供**陪同就医**服务——帮助用户完成挂号、签到、引导就诊、取药、取报告、记录医嘱等环节，从而提升就医效率与体验。

> ⚠️ 边界声明：陪诊师**不提供医学诊断、不开药、不做治疗**；仅做就诊流程上的陪同与辅助，避免触及《医疗机构管理条例》《互联网诊疗管理办法》等法规红线。

## 1.2 项目目标

| 维度 | 目标 |
| :-- | :-- |
| 用户侧 | 让"一个人也能轻松看病"成为现实；患者就医时间平均缩短 30%+ |
| 陪诊师侧 | 为自由职业者 / 兼职者提供稳定、合规、有保障的接单平台 |
| 平台侧 | 建立可规模化、可监管的双边服务市场，逐步覆盖 100+ 城市、500+ 医院 |
| 合规侧 | 严格区分"陪诊"与"诊疗"，建立完整资质审核与保险机制 |

## 1.3 项目范围（v1.0）

### 1.3.1 In-Scope（本期包含）

1. **三类角色**：患者、陪诊师、管理员
2. **陪诊师入驻**：注册 → 实名 → 资质提交 → 培训考核 → 审核上线
3. **患者下单**：按医院、时间、服务类型下单；支持"系统匹配"和"指定陪诊师"两种模式
4. **匹配 / 接单**：智能匹配 + 抢单 / 派单双轨
5. **服务过程**：到院签到、关键节点打卡、服务结束确认
6. **支付与结算**：微信支付、预付 + 补差价、T+N 结算陪诊师
7. **评价与申诉**：双向评价、申诉处理
8. **基础运营**：医院库、套餐管理、价格配置、优惠券、客服工单
9. **多端**：iOS App、Android App、微信小程序（三端核心功能对齐）

### 1.3.2 Out-of-Scope（本期不含，留待后续版本）

- 互联网诊疗 / 在线问诊 / 电子处方
- 陪诊师医保结算或商保直付
- 跨境 / 涉外陪诊
- 医院 HIS / 医生工作站系统对接（仅在用户授权下做号源展示）
- AI 自动派单模型（v1 使用规则匹配 + 人工可干预）

## 1.4 用户画像

### 患者

| 类型 | 占比预估 | 典型诉求 |
| :-- | :--: | :-- |
| 老年人独自就医 | 35% | 流程引导、防走丢、医嘱记录 |
| 异地就医 | 20% | 提前熟悉流程、当天全陪 |
| 孕妇 / 产妇 | 15% | 排队久站不便、需家属陪同 |
| 慢病复查 | 15% | 多次往返、需要代办 |
| 子女代父母下单 | 10% | 远程下单、看护父母 |
| 其他 | 5% | — |

### 陪诊师

| 类型 | 占比预估 | 典型特征 |
| :-- | :--: | :-- |
| 全职 | 30% | 持有健康证、医护背景、有时间稳定接单 |
| 兼职医护学生 | 30% | 时间灵活、素质较好、需培训 |
| 兼职社会人员 | 30% | 通过培训考核上岗、有医院熟悉度 |
| 医院内导医转化 | 10% | 院内资源丰富 |

### 管理员

- **总部运营**：策略、价格、活动、客服
- **城市经理**：本地陪诊师管理、本地医院拓展
- **审核员**：资质审核、申诉处理
- **财务**：对账、提现、发票

## 1.5 术语与缩略语

| 术语 | 含义 |
| :-- | :-- |
| 陪诊师 | 在医院为患者提供就诊陪同与流程协助的服务人员（**非医务人员**） |
| 患者 / 用户 | 购买陪诊服务的需求方 |
| 订单 | 一次陪诊服务的履约单元 |
| 抢单池 | 平台向多个陪诊师推送的可被抢订单的集合 |
| 派单 | 平台将订单定向分配给某一陪诊师（通常因专业匹配或地域唯一） |
| 接单 | 陪诊师确认承接某一订单 |
| 服务包 / 套餐 | 标准化的服务组合（如"半日陪诊""全日陪诊""代取报告"） |
| 补差价 | 实际服务时长 / 项目超出套餐范围产生的额外费用 |
| 结算 | 平台将订单款项扣除佣金后打款给陪诊师 |
| 抽佣 | 平台对每笔订单收取的服务费比例 |
| SLA | Service Level Agreement，服务水平协议 |
| 资质 | 陪诊师上岗所需的证件（身份证、健康证、学历 / 医护背景等） |
| 培训考核 | 平台强制性的线上学习 + 测验，是陪诊师上线的前置条件 |

## 2. 业务关键假设

| # | 假设 | 风险 | 应对 |
| :-- | :-- | :-- | :-- |
| A1 | 用户量级：上线 6 个月 MAU 5 万、订单 1k/日 | 流量波动 | 系统按 10x 设计容量 |
| A2 | 主要支付通道：微信支付 | 政策变化 | 预留支付宝、银联接入 |
| A3 | 陪诊师抽佣 15%~25% | 行业竞争导致下调 | 抽佣可后台灵活配置 |
| A4 | 客单价：150~400 元/单 | 单价过低不可持续 | 提供增值服务（接送、住院陪护） |
| A5 | 服务时长：单次 3~6 小时为主 | 长尾订单 | 服务包按小时计费兜底 |
