## 一、项目一句话

**陪诊师平台** 是一个连接 **患者**、**陪诊师** 与 **平台运营方（管理员）** 的双边服务撮合平台。  
核心场景是患者（尤其是老年人、孕妇、异地就医、行动不便者等）通过 App / 小程序下单，平台根据时间、医院、病情等维度匹配具备资质的陪诊师，由陪诊师在医院端为患者提供挂号、就诊引导、取药、检查陪同、医嘱记录等全程陪同就医服务。

## 四、关键决策摘要

| 决策项 | 结论 | 备注 |
| :-- | :-- | :-- |
| 支持端 | iOS App、Android App、微信小程序 | 三端共享一套后端、统一账号 |
| 主要交互端 | 微信小程序 | 优先保证小程序体验，iOS/Android 提供同等核心能力 |
| 核心业务流 | 患者下单 → 平台匹配 / 患者自选陪诊师 → 陪诊师接单 → 到院服务 → 结束 + 评价 → 结算 | 详见 04 |
| 支付方式 | 微信支付为主，预付 + 完成后补差价 | 详见 04、08 |
| 资金结算 | T+N 或 T+1 结算给陪诊师，平台抽佣可配置 | 详见 04、08 |
| 实名 / 认证 | 全部用户须实名；陪诊师额外需健康证 + 资质证书审核 | 详见 02、05 |
| 合规 | 不涉及诊疗行为，陪诊师不提供医学建议，仅做就诊陪同 | 重要边界 |
| 紧急安全 | 一键报警、行程实时上报、紧急联系人 | 详见 05 |
