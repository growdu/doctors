# 08 · 接口需求

> 本章描述内部 API 规范、与三方对接的关键点。  
> API 详细字段以 OpenAPI 3.0 文档为准（仓库 `api/openapi.yaml`），本章给出**设计原则与关键列表**。

---

## 8.1 设计原则

1. **RESTful 风格**：资源名词复数，HTTP method 表示动作；查询参数过滤、分页。
2. **统一前缀**：`/api/v1/...`
3. **统一响应**：

```json
{
  "code": 0,
  "message": "ok",
  "data": { ... },
  "trace_id": "abc123"
}
```

4. **错误码**：业务码 5 位（10001~19999），系统码 6 位（500xxx）。
5. **鉴权**：除登录、注册、找回密码外，全部接口需 `Authorization: Bearer <jwt>`。
6. **幂等**：所有写接口支持 `Idempotency-Key` 头，24h 内同 key 不重复执行。
7. **分页**：`page`（从 1 起）、`page_size`（默认 20，最大 100），返回 `total`、`has_more`。
8. **时间**：所有时间字段 ISO8601 + 时区（`+08:00`）。

## 8.6 三方对接

### 8.6.1 微信生态

| 能力 | 用途 | 接入方式 |
| :-- | :-- | :-- |
| 微信登录 | App / 小程序一键登录 | OAuth2.0、code2Session |
| 微信支付 | 订单支付 | JSAPI（小程序）、App 支付 |
| 微信模板消息 | 服务通知（小程序） | subscribeMessage |
| 客服消息 | 客服回复 | 客服 API |
| 微信分享 | 拉新分享 | wx.share / sdk |

### 8.6.2 实名 / 活体

- **场景**：注册、提现
- **服务商**：阿里云实人认证 / 腾讯云慧眼 / 网易易盾（三选一或双备）
- **接口**：提交身份证 + 姓名 + 活体视频 / 照片
- **存储**：仅保留哈希 + 末四位

### 8.6.3 短信

- **场景**：验证码、通知
- **服务商**：阿里云 / 腾讯云
- **模板**：需提前报备

### 8.6.4 推送

- **端**：iOS（APNs）、Android（厂商通道 + 第三方推送）、小程序（模板消息）
- **服务商**：个推 / 极光 / 腾讯移动推送 / 阿里移动推送
- **策略**：按用户分通道，避免打扰

### 8.6.5 地图 / 定位

- **服务商**：高德 / 腾讯
- **能力**：定位、地址解析、距离计算、医院 POI

### 8.6.6 银行 / 打款

- **场景**：陪诊师提现、企业付款
- **通道**：微信企业付款到零钱 / 银行卡
- **要求**：商户号开通"企业付款"权限；合规留存付款凭证

### 8.6.7 文件存储

- **场景**：证件照、过程照片
- **服务商**：OSS / COS
- **安全**：上传走服务端中转 + 签名 URL；不开放前端直传 OSS

## 8.7 接口安全清单

- [x] 所有接口必须鉴权（除登录、注册、验证码、公开配置）
- [x] 所有写接口必须幂等
- [x] 限流：登录 5/min/IP、验证码 1/60s/手机号、下单 5/min/用户
- [x] 错误响应不得泄漏堆栈、SQL、内部地址
- [x] 跨域：仅允许配置的白名单
- [x] 敏感字段（身份证、电话）响应必须脱敏

---

## 8.8 错误码规范

| 范围 | 含义 |
| :-- | :-- |
| 0 | 成功 |
| 1xxx | 通用业务（参数、状态、权限） |
| 11xx | 账号相关 |
| 12xx | 订单相关 |
| 13xx | 支付相关 |
| 14xx | 评价相关 |
| 15xx | 陪诊师相关 |
| 2xxx | 资源 / 数据不存在 |
| 3xxx | 三方调用失败（微信 / 实名 / 短信） |
| 4xxx | 风控拦截 |
| 5xxxx | 系统异常 |

> 客户端需按 `code` 做**用户可读**提示，不能直接展示后端 `message`。
